CSS Color Reference

CSS colors are used to define the color of text, backgrounds, borders and other elements.

Ways to Specify Colors

  • Color Name - Example: red, blue, green.
  • HEX - Example: #ff0000.
  • RGB - Example: rgb(255, 0, 0).
  • RGBA - Example: rgba(255, 0, 0, 0.5).
  • HSL - Example: hsl(0, 100%, 50%).
  • HSLA - HSL with transparency.
