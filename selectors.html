CSS Selectors Reference

CSS selectors are used to select HTML elements for applying styles.

Types of Selectors

  • Element Selector - Selects elements by tag name.
  • Class Selector - Selects elements using a class.
  • ID Selector - Selects an element using an ID.
  • Universal Selector - Selects all elements.
  • Attribute Selector - Selects elements based on attributes.
  • Group Selector - Selects multiple elements together.

Examples

p { color: blue; }

.box { background-color: yellow; }

#heading { font-size: 30px; }
