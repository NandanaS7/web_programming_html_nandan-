CSS Default Values

CSS properties have default values that are applied when a value is not explicitly specified.

Examples

  • color - Usually inherited from the parent element.
  • display - Depends on the HTML element.
  • position - static.
  • opacity - 1.
  • font-weight - normal.
  • text-align - start.
  • visibility - visible.

Default values can be changed by specifying another value in the CSS rule.
