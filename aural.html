CSS Aural Reference

Aural CSS was designed to control how web content is presented through speech synthesizers and other audio devices.

Aural Properties

  • volume - Controls the volume of speech.
  • voice-family - Specifies the voice family.
  • speech-rate - Controls the speaking rate.
  • pause - Specifies pauses before or after content.
  • cue - Specifies audio cues.

Modern web development generally uses accessibility technologies instead of the older aural CSS features.
