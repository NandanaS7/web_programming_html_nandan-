CSS Units

CSS units are used to specify the size, spacing and dimensions of elements.

Types of CSS Units

Absolute Units

  • px - Pixels
  • cm - Centimeters
  • mm - Millimeters
  • in - Inches
  • pt - Points
  • pc - Picas

Relative Units

  • % - Percentage
  • em - Relative to the font size.
  • rem - Relative to the root font size.
  • vw - Viewport width.
  • vh - Viewport height.
