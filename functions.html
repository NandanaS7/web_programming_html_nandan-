CSS Functions Reference

CSS functions are used to perform operations and provide values to CSS properties.

Common CSS Functions

  • rgb() - Defines a color using RGB values.
  • rgba() - Defines a color with transparency.
  • calc() - Performs calculations.
  • var() - Uses a CSS custom property.
  • url() - Specifies a URL.
  • linear-gradient() - Creates a linear gradient.
  • translate() - Moves an element.
