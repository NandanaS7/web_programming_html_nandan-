CSS Animatable Reference

Animatable CSS properties are properties whose values can change gradually during an animation.

Common Animatable Properties

  • color - Text color can be animated.
  • background-color - Background color can be animated.
  • width - Width can be animated.
  • height - Height can be animated.
  • opacity - Transparency can be animated.
  • transform - Position, rotation and scale can be animated.
  • margin - Margins can be animated.
  • padding - Padding can be animated.
